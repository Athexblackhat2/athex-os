# ATHEX OS — Build Kit

A Kali-Linux-based custom distro, rebranded as **ATHEX OS**, built with Debian/Kali `live-build`.
Includes: custom name/branding, boot splash (Plymouth), wallpaper/logo, `athex-about` developer-info
command, and a generic pentest toolkit preinstalled.

Since you only have **VMware Workstation** (no standalone Linux box), you'll build it in two stages:

---

## Stage 1 — Build the ISO inside a Kali VM

1. In VMware Workstation, create a normal VM from the official Kali Linux installer ISO
   (download from kali.org if you don't have one). 4+ CPU cores, 8GB+ RAM, 40GB+ disk, NAT networking.
2. Install Kali normally, boot into it, make sure it has internet access.
3. Copy this whole `athex-build` folder into that VM (shared folder, scp, or drag-and-drop if
   VMware Tools is installed).
4. Inside the Kali VM, open a terminal:
   ```bash
   cd athex-build
   chmod +x build-athex.sh
   sudo ./build-athex.sh
   ```
5. Wait — this downloads ~4-6GB of packages and builds the filesystem. 30-90 minutes depending
   on your connection and disk speed.
6. When it finishes you'll have `athex-os-YYYYMMDD.iso` in that same folder.

## Stage 2 — Run ATHEX OS as its own VM

1. Copy `athex-os-YYYYMMDD.iso` out of the build VM onto your Windows/Mac host.
2. In VMware Workstation: **File → New Virtual Machine → Installer disc image (.iso)** → point
   to `athex-os-*.iso`.
3. Boot it. You'll see the ATHEX OS Plymouth splash, then the XFCE desktop with the ATHEX
   wallpaper and a Kali-Dark theme.
4. Open a terminal and run `athex-about` to see the developer/system info panel.

## What's customized

| Item | File |
|---|---|
| OS name/identity | `branding/etc/os-release` |
| Login banner (MOTD) | `branding/etc/motd` |
| Developer info command | `branding/usr/local/bin/athex-about` |
| Wallpaper + logo | `branding/usr/share/backgrounds/athex/*.png` |
| Boot animation | `branding/usr/share/plymouth/themes/athex/*` |
| GRUB name, LightDM background, XFCE wallpaper | `hooks/0100-athex-branding.hook.chroot` |
| Preinstalled tools | `package-lists/athex.list.chroot` (generated by `build-athex.sh`) |

## Customizing further

- **Swap the logo/wallpaper later:** regenerate or replace the PNGs in
  `branding/usr/share/backgrounds/athex/` and `branding/usr/share/plymouth/themes/athex/logo.png`,
  then re-run `build-athex.sh`.
- **Add your own GitHub tools:** open `build-athex.sh`, find the `package-lists/athex.list.chroot`
  heredoc, and either (a) add the package name if it's in the Kali/Debian repos, or (b) add a
  `git clone <your-repo>` line inside `hooks/0100-athex-branding.hook.chroot` to pull and install
  your tool's source directly into the image at build time.
- **Rename things further:** `os-release`, `motd`, and `athex-about` are plain text/bash — edit freely.

## Notes

- This uses the real Kali package repos, so the resulting ISO is a legitimate, fully-functional
  Kali-based system — just rebranded and pre-configured as ATHEX OS.
- Build must happen on a machine with internet + enough disk (the Kali build VM). It cannot be
  done without network access to Kali's mirrors.
